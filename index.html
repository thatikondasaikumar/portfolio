🏗️ Fatal Road Crash Analytics — Data Warehouse & BI Solution

Designed and built a production-grade data warehouse analyzing 35+ years of Australian fatal crash data to support government road safety policy decisions. Applied Kimball's dimensional modeling methodology to create a scalable, query-optimized analytical platform supporting multidimensional OLAP analysis.

Toolset: PostgreSQL, Python (pandas), Docker, SQL, Tableau, Association Rule Mining (mlxtend)

  • Star Schema Design: Architected an 8-dimension star schema (DimDate, DimLocation, DimCrashType, DimSpeedLimitCategory, DimVehicleInvolvement, DimHoliday, DimWeekdayWeekend, DimDwelling) with concept hierarchies enabling drill-down/roll-up operations across temporal, spatial, and demographic dimensions.
  • ETL Pipeline Development: Built Python-based ETL workflow processing 50,000+ crash records and 189,000+ dwelling records; handled data quality issues including placeholder values (-9), missing data, and LGA name inconsistencies through custom mapping and standardization logic.
  • Data Integration: Merged crash, fatality, and dwelling datasets; performed categorical binning (dwelling density: Low/Medium/High/Very High) to enable demographic-based crash analysis.
  • Query Optimization: Designed StarNet query model with footprints supporting efficient multidimensional analysis; implemented complex SQL queries answering 5 strategic business questions about crash trends, high-risk zones, speed-related fatalities, and temporal patterns.
  • Business Intelligence: Created interactive Tableau dashboards with choropleth maps identifying LGA-level crash hotspots; delivered time-series visualizations revealing 58% crash reduction (1989-2020) followed by concerning post-2020 reversal trend.
  • Advanced Analytics: Applied association rule mining (Apriori algorithm) with 0.05 min support and 0.5 min confidence thresholds; discovered high-risk patterns (e.g., weekday + multi-vehicle + male driver combinations showing 52.7% driver involvement with 1.17 lift).
  • Policy Recommendations: Generated evidence-based safety interventions targeting weekday traffic enforcement, high-speed zone redesign, and driver education programs based on data-driven pattern discovery.
  • Database Implementation: Deployed PostgreSQL database with referential integrity constraints; used COPY command for efficient bulk loading; validated schema through ERD generation and query testing.

📊 Key Insights Delivered

  • NSW had highest fatality count with "Very High" dwelling density areas contributing most deaths
  • High-speed zones showed highest fatality rates, dominated by single-vehicle crashes (driver fatigue likely)
  • Weekday crashes 46% higher than weekends, indicating commute-related risk concentration
  • Post-2020 crash reversal trend identified, signaling need for renewed safety interventions
  • Top 50 LGA hotspots mapped geographically for targeted resource allocation

🛠️ Technical Implementation

  • Data Volume: 50K+ crash records, 189K+ dwelling records, 35+ years temporal range
  • Schema Complexity: 8 dimensions with parallel hierarchies (e.g., State→LGA and Dwelling Category paths)
  • ETL Automation: Dockerized Python pipeline with pandas-based transformation logic
  • Data Quality: Standardized "MISSING" placeholder handling; custom LGA name reconciliation
  • Query Performance: Star schema design optimized for OLAP aggregation queries
